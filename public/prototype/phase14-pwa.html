What does Karpathy say about token vocabulary trade-offs?
Karpathy explains that increasing vocabulary size shortens sequence lengths but significantly enlarges the embedding matrix parameter table [08:30]. Conversely, smaller vocabularies increase sequence lengths, raising self-attention compute quadratically [12:10].

Compare SQLite WAL mode with standard rollback journaling.
In SQLite, **Write-Ahead Logging (WAL)** provides concurrent readers while a writer writes [1]. Readers do not block writers, and writes append sequentially to the `-wal` file instead of locking the main database file.
