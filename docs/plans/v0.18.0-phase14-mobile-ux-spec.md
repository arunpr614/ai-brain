## 1. Design Philosophy: The Focused Mobile Reader & Quick Capture Companion

The desktop web app functions as a comprehensive thinking and management workbench (bulk triage, server ASR deck administration, database queries, and multi-model configuration).

In contrast, the **Pixel 7 Pro Mobile Experience** is strictly designed for **four high-frequency postures**:
1. **Quick Capture on the go**: Share sheets, 1-tap thoughts, pasting links.
2. **Distraction-Free Reading**: Clean long-form reader, synchronized YouTube transcripts.
3. **Reflective Note Taking & AI Digestion**: View AI summaries, capture personal notes with local durability.
4. **Scoped In-Item AI Companion**: Ask questions about the current document and inspect cited evidence.

## 2. Touch Ergonomics & Viewport Sizing

### 2.1 Viewport Stability
- Use `min-h-[100dvh]` and dynamic viewport calculations to prevent Android Chrome address bar jump artifacts.
- Navigation bar and bottom sheets observe `pb-[max(env(safe-area-inset-bottom),0.5rem)]`.

### 2.2 Minimum Touch Targets
- All interactive controls (tabs, action chips, buttons, citation triggers) have a **minimum touch target of 48px × 48px** for ergonomic single-thumb interaction.

### 2.3 Visual Hierarchy & Typography Tokens
- **Editorial Headlines**: `font-serif` Newsreader / Charter for reader headers (22px-28px font size, 1.25 line height).
- **Body Content**: Clean Inter sans-serif (16px base, 1.6 line height for reading comfort).
- **Card Subtext**: 13px muted typography with source platform icons and quality indicators.

## 3. Core Mobile Screen Layouts

### 3.1 Mobile Library
- **Header**: Sticky search bar with 1-tap clear, count pill, and offline status indicator.
- **Filter Chips**: Horizontal scrollable carousel (`[All]`, `[YouTube]`, `[Articles]`, `[PDFs]`, `[Notes]`, `[Needs Upgrade]`, `[Offline]`).
- **Cards**: Simplified mobile card with source platform icon, title, quality badge, relative timestamp, and offline checkmark. Single tap navigates directly to the Reading Studio.

### 3.2 Reading Studio (Item Detail)
- **Top Bar**: Back to library arrow, item quality badge, font size / theme toggle, and share action.
- **Media Header**: Responsive video embed (or audio player) for YouTube videos with transcript synchronizer.
- **Segmented Layer Tabs**:
  - `[Content / Transcript]`: Clean reader with tap-to-seek timestamped transcript lines.
  - `[AI Digest]`: Multi-section summary, key takeaways, and discussion points.
  - `[My Notes]`: Touch markdown editor with keyboard accessory toolbar.
  - `[Ask AI]`: Mobile streaming chat scoped to the active item.

### 3.3 Touch Note Editor
- Accessory toolbar docked above virtual keyboard (`[H2]`, `[Bold]`, `[Italic]`, `[List]`, `[Checkbox]`, `[Quote]`, `[Link]`).
- 1-tap "Import AI Takeaways" button to append synthesized insights into the personal note.
- Real-time auto-save with IndexedDB local journal resilience.

### 3.4 In-Item AI Chat & Citation Drawer
- Mobile conversation stream with message bubbles and smooth auto-scroll.
- Tapping a citation chip (`[p. 3]`, `[04:12]`) opens an expandable bottom-sheet drawer displaying the exact retrieved passage without losing conversation context.
