# Architectural Decision Log: PWA Domain Deployment Strategy

**Date:** 2026-08-22  
**Status:** Approved & Adopted  
**Primary Production Origin:** `https://brain.arunp.in`  
**Target Device:** Google Pixel 7 Pro (412×890px CSS viewport, 120Hz LTPO)  

---

## 1. Context & Objective

Phase 14 delivers the **Mobile PWA & Android Companion** for AI Brain, incorporating a touch-first bottom navigation bar, 1-tap quick capture modal, citation preview slide-up drawer, touch Markdown accessory toolbar, offline storage manager, and Service Worker v6 runtime cache.

An architectural evaluation was conducted to determine whether to:
1. **Option A (Adopted):** Deploy Phase 14 directly under the single, unified production domain **`https://brain.arunp.in`**.
2. **Option B:** Separate mobile PWA traffic onto a dedicated subdomain **`brainpwa.arunp.in`**.

---

## 2. Decision & Evaluation Matrix

| Decision Criteria | Single Unified Domain (`brain.arunp.in`) | Separate Subdomain (`brainpwa.arunp.in`) | Winning Choice |
|---|---|---|---|
| **Authentication & SSO** | Single session cookie (`brain-session`); zero cross-origin friction; no re-login required when switching devices. | Requires multi-domain cookie scoping (`Domain=.arunp.in`) or independent login sessions. | **`brain.arunp.in`** |
| **Offline Storage & CacheStorage** | Unified origin cache: saved offline articles and notes in CacheStorage & IndexedDB are directly shared between browser and PWA mode. | Browser storage is origin-partitioned. Cached items on `brain.arunp.in` are unavailable on `brainpwa.arunp.in`. | **`brain.arunp.in`** |
| **CORS & Network Overhead** | Pure same-origin requests; 0ms preflight `OPTIONS` overhead for API endpoints. | Cross-origin fetches require explicit `Access-Control-Allow-Origin` headers and preflight handling. | **`brain.arunp.in`** |
| **URL Consistency & Deep-Linking** | Uniform links across mobile and desktop. Links shared via Android Web Share Target resolve identically on all clients. | Fragmented URLs: links generated on mobile contain `brainpwa` prefix, requiring redirects on desktop. | **`brain.arunp.in`** |
| **Operational & Maintenance Cost** | 1 DNS record, 1 SSL certificate, 1 Nginx virtual host configuration. | 2 DNS records, 2 SSL certificates, duplicate reverse proxy configs. | **`brain.arunp.in`** |
| **Layout & Ergonomics Handling** | Handled purely via responsive design (`md:hidden` bottom nav vs `hidden md:flex` sidebar rail) and safe-area insets. | Unnecessary infrastructure-level duplication for what CSS/React handles natively. | **`brain.arunp.in`** |

---

## 3. Policy & Implementation Directives

1. **Production Deployment Target:**  
   All Phase 14 PWA enhancements are deployed to **`https://brain.arunp.in`**.
2. **PWA Installation Procedure:**  
   Users install the PWA directly by navigating to `https://brain.arunp.in` in Chrome on Android and choosing **"Install app"** / **"Add to Home screen"**.
3. **Role of Subdomain `brainpwa.arunp.in`:**  
   The `brainpwa.arunp.in` subdomain is strictly reserved for an **Isolated Staging / Canary sandbox** if experimental mobile pull requests or breaking schema changes require isolated validation before production promotion.
